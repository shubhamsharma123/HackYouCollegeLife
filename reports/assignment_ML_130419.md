## Q1. what is neural network
A **neural network** is a computer model that imitates the way human brains work.  
1. **Neurons** – Small units that take inputs, multiply them by weights, add a bias, and send the result forward.  
2. **Layers** – Neurons are grouped into layers: an input layer, one or more hidden layers, and an output layer.  
3. **Learning** – The network adjusts the weights and biases during training so that its outputs match known correct answers.  
4. **Activation function** – A rule that decides whether a neuron fires, adding non‑linear behaviour.  
5. **Applications** – Recognizing speech, classifying images, predicting stock prices, and many other pattern‑recognition tasks.  

In short, a neural network is a set of connected, adjustable units that learn to map inputs to outputs.
